Breakout room - Handed a dataset

Scenario

Handed a dataset: you’ve received data from Bioconductor’s ExperimentHub. What metadata or provenance would you expect that isn’t there?

The dataset

“All scRNAseq datasets have the import scripts in the package source code, e.g., https://github.com/LTLA/scRNAseq/blob/master/scripts/zeisel-brain-2015/2023-12-14.Rmd”

Load R packages

suppressPackageStartupMessages(library(scRNAseq))

Fetch data

sce.zeisel <- ZeiselBrainData(
  ensembl = TRUE, # use Ensembl identifiers rather than gene symbols (default: FALSE)
  location = TRUE, # include genomic coordinates (default: FALSE)
  legacy = FALSE   # pull data from gypsum backend, not ExperimentHub
)
